# 🤖 AI Agent Instructions (AGENTS.md)

This document contains the automated protocol that any Artificial Intelligence agent (Claude Code, Cursor, Antigravity, GitHub Copilot CLI, Codex, etc.) must follow to install, configure, and verify **ReVox** on the user's machine.

---

## 🎯 Agent Goal
Your goal is to leave the environment completely operational without requiring the user to configure technical dependencies manually. Upon completion, the user must have:
1. System and Python dependencies installed.
2. The `.venv` virtual environment configured with `requirements.txt`.
3. The `.env` file initialized (with or without token).
4. The `ReVox Control Panel.lnk` shortcut created on the user's Desktop.
5. The web panel verified and ready to use.

---

## 📋 Execution Steps for the Agent

### Step 0: Clone the Repository (if not already inside the project)

If the user invoked you in an empty folder, clone the official repository and navigate into it:
```powershell
git clone https://github.com/John54571/ReVox-Bot.git
cd ReVox-Bot
```

### Step 1: System Prerequisites Verification

1. **Python 3.11+:**
   - Run: `python --version`
   - If not installed or below 3.11, install it via:
     ```powershell
     winget install Python.Python.3.11
     ```

2. **FFmpeg:**
   - Run: `ffmpeg -version`
   - If not installed, install it via:
     ```powershell
     winget install Gyan.FFmpeg
     ```
   - *Note:* FFmpeg is essential to encode audio generated by VoiceStudio into Opus packets for Discord.

3. **VoiceStudio (Local TTS Engine):**
   - Check if the local API is responding by running:
     ```powershell
     try { (Invoke-WebRequest http://127.0.0.1:3900/.well-known/voicestudio-speech -UseBasicParsing -TimeoutSec 3).StatusCode } catch { "offline" }
     ```
   - If *offline*, remind the user politely: *"VoiceStudio is not currently running; remember to launch it before generating voice."*

---

### Step 2: Virtual Environment & Dependency Installation

1. Create the virtual environment if it does not exist:
   ```powershell
   if (-not (Test-Path ".venv")) { python -m venv .venv }
   ```

2. Install exact dependencies with pip:
   ```powershell
   .\.venv\Scripts\pip install -r requirements.txt
   ```
   *(Includes `discord.py[voice]>=2.7.1`, `davey>=0.1.7` for Discord DAVE E2EE protocol, `aiohttp`, and `python-dotenv`).*

---

### Step 3: Configure `.env` File

1. If `.env` does not exist, create it from the template:
   ```powershell
   if (-not (Test-Path ".env")) { Copy-Item .env.example .env }
   ```
2. If the user provided a Discord token in their prompt, inject it directly into `.env`:
   ```ini
   DISCORD_TOKEN=user_token_here
   ```
3. If VoiceStudio is running, you can inspect available voice profiles:
   ```powershell
   (Invoke-RestMethod http://127.0.0.1:3900/v1/audio/voices).voices | Where-Object type -eq "profile" | Select-Object voice_id, name
   ```
   If the user requested a specific voice (e.g. `Dokuro`), assign its `voice_id` (e.g. `188d7f2b`) to `VOICESTUDIO_VOICE=` in `.env`.

---

### Step 4: Generate Desktop Shortcut

Execute the automated script to create the desktop shortcut with the official ReVox icon:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\crear_acceso_directo.ps1
```
This will create `ReVox Control Panel.lnk` on the user's Desktop pointing to `iniciar_panel.bat`.

---

### Step 5: Smoke Test & Verification

Verify that the main modules import without errors:
```powershell
.\.venv\Scripts\python -c "import bot, panel; print('ReVox OK')"
```

---

## 📢 Final Message to the User
Once the protocol is complete, inform the user:
- Dependencies (`.venv`, `FFmpeg`, packages) are installed.
- The **ReVox Control Panel** shortcut is ready on their Desktop.
- They can open the web interface at **http://127.0.0.1:5050** to configure their token if not done yet and click *"Start Bot"*.
